# Contribuição

Este projeto é mantido sob a identidade de seus próprios mantenedores.

Ao criar commits, tags, releases ou configurações de publicação, use somente
o nome e o e-mail Git do mantenedor responsável. Não adicione créditos,
assinaturas, trailers ou metadados referentes a ferramentas externas de
assistência, geração ou automação.

Antes de publicar, confirme:

- `git config user.name` identifica o mantenedor;
- `git config user.email` usa um endereço controlado pelo mantenedor;
- mensagens de commit e arquivos do projeto não contêm referências externas;
- nenhum segredo, ambiente virtual ou arquivo local foi incluído.
