# Convenção de sinal nas verificações estruturais

Nas rotinas de verificação do OSA, interpretar os resultados de esforço normal conforme esta convenção:

- esforço normal negativo: tração;
- esforço normal positivo: compressão.

Aplicar essa convenção ao selecionar e calcular as solicitações de cada verificação. Usar o módulo do esforço para obter a magnitude solicitante depois de classificar o sinal. A convenção usada pelo solver não altera essa regra interna do OSA.

Não alterar renderizações ou apresentações do programa para representar essa convenção. O ajuste deve ocorrer somente na leitura dos resultados pela camada de verificação.
